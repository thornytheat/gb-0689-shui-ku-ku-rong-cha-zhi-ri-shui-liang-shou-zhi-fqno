# 水位与水量定义

id、station为字符串。time含时区，统一UTC，日账在+08:00午夜拆分。level单位m；inflow/outflow单位m3/s或L/s，归一m³/s；空值不等于零。负流量与曲线外水位隔离。
curve为[[水位,库容],...]，水位及库容必须严格递增，库容非负，单位m与m³。只对范围内水位分段线性插值，端点允许。
同站同刻按version最高记录采信，同版不同值全部隔离。重复旧版有独立证据。输入=采信+隔离；原始行号保留。
相邻观测间以梯形积分计算流量体积，超过max_gap_hours则不插补。日界处先线性插出流量与水位，再分别积分及按曲线换算库容。日账是已覆盖时段的收支，覆盖不足24h始终待补测。
日收支差=库容变化-入库+出库，绝对值超过tolerance_m3需复核。缺测优先于超差。无蒸发降雨模型，差额不自动认作漏损。
数值为Decimal字符串，日切与整段积分容许1e-9m³以内十进制除法尾数。规则参数和输入摘要参与幂等ID；批次原子保存，复核版本冲突返回409。

原始到达序小于此前最大事件时刻的测次标记arrival=迟到，仍保留并按事件时间排序积分，迟到不会推进水位回退。

## 补传修订（M6 复核页）

观测日志可补传同站同刻的修订测次，在 M6 页面办理，不直接覆盖任何已存批次。

- 原批次与已复核日账保留原貌：批次 payload 只追加不更新；原始 CSV 随批次存入 `sources`，证据导出随该批次版本固定。
- 同站同刻按测次 `version` 裁决：最高版本采信；同版同值时补传行（新到达）优先，原批次行记 `DUPLICATE`；高版本替代低版本，被替代行记 `SUPERSEDE`。
- 迟到旧修订（补传版本低于已采信版本）记 `STALE_REVISION`，不进入重算、不倒写现行值，仅留痕。
- 同版本且水文值矛盾记 `CONFLICT`，整组进入待裁决栏，由人工选定保留行（来源行号 `base:n`/`rev:n`），裁决前不派生按日变化、不得切换现行。
- 替代日账由原批次原料与补传行合并后经同一管线重算，内容寻址生成新批次；受影响观测时刻及其相邻积分段所落 +08 日期列入受影响日，按日列出入库、出库、库变、收支差、覆盖与状态的新旧变化（数值按 Decimal 比较）。
- 补传任务按六步检查点推进（解析、合并、影响日、重算、差异、候命），每步确认落盘；落库中断后重办同一修订从最后确认进度续跑，同内容重办幂等、候选批次不变。
- 仅当无待裁决冲突且替代批次复核“通过”，才允许切换现行日账；切换为单行指针的单事务更新，乐观锁不匹配返回 409 并保留旧版。
- 替代批次证据 CSV 在原证据后追加补传块（任务、原批次、摘要、迟到/替代/重复/冲突留痕与按日变化）；原批次证据不含该块。

不建蒸发降雨及地下渗漏模型，不接外部调度控制；补传只改变观测采信与重算结果，收支差仍保留待人工归因。
